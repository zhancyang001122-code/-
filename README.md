# 极简自定义闹钟 (CustomAlarmApp)

一款超轻量级、无后台常驻运行负担的 Android 自定义闹钟。

## ✨ 特性
1. **指定具体日期与时间**：支持设定未来特定某一年某一天的精确时间戳。
2. **灵活循环规则**：
   - 单次特定日期
   - 每天
   - 工作日（周一至周五）
   - 每隔 N 天（自定义步长轮班模式）
3. **历史记录与快捷套用**：
   - 自动记录最近使用过的闹钟参数，顶部横向快捷滑动卡片，点击一键套用。
4. **极致轻量 & 零后台常驻**：
   - 采用系统硬件级 `AlarmManager.setExactAndAllowWhileIdle`，无需常驻后台 Service，与系统自带闹钟耗电一致。
   - 采用 Android 原生轻量存储，启动极快。

## 🚀 如何使用 GitHub Actions 自动在线打包 APK（零本地配置）
1. 在 GitHub 上新建一个免费私有或公开仓库（例如命名为 `my-alarm-app`）。
2. 将本工程的所有文件上传（或 git push）到该仓库。
3. 仓库被推送后，点击 GitHub 页面上方的 **Actions** 标签栏。
4. 你会看到名为 **Build Android APK** 的工作流自动开始运行（大约耗时 1~2 分钟）。
5. 运行完毕后，点击该工作流记录，在最下方的 **Artifacts** 区域即可直接下载 `CustomAlarm-Debug-APK.zip`，解压即为可安装的 `.apk` 安装包！
